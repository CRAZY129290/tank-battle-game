# 坦克大战 · Tank Battle

一个用纯 HTML / CSS / JavaScript 编写的经典《坦克大战》(Battle City) 网页游戏，**单文件即可运行**，无需任何依赖。

## 玩法

- 控制己方坦克消灭所有敌军，并保护底部的基地（鹰徽）。
- 基地被击毁，或己方生命耗尽，游戏结束。
- 连续通过 3 关即可获胜。

## 操作

| 按键 | 动作 |
| --- | --- |
| 方向键 / `W A S D` | 移动 |
| 空格 / `J` / `X` | 射击 |
| `Enter` | 开始 / 重新开始 |
| `M` | 静音 |

移动端支持屏幕虚拟按键。

## 特性

- 4 种敌军：普通 / 快速 / 火力 / 装甲
- 地形：砖墙、钢墙、水域、树林（坦克可从树下穿过）
- 道具系统：护盾、生命、火力升级、冰冻
- 粒子爆炸效果与 Web Audio 音效
- 3 张关卡地图，难度递增

## 运行

直接用浏览器打开 `index.html` 即可，无需安装依赖。
